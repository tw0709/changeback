> 권리자의 사전 허락이 있거나 관련 법령에 따라 허용되는 경우를 제외하고, 본 소프트웨어의 저작권 보호 대상 콘텐츠를 무단으로 복제·수정·재배포하거나 다른 소프트웨어에 사용하는 행위를 허용하지 않습니다.
>

### 자동화 분석 도구의 이용

본 소프트웨어에 관한 지식재산권 보호 원칙은 분석에 사용된 도구의 종류와 관계없이 적용됩니다.

여기에는 다음과 같은 방법이 포함될 수 있습니다.

- AI 에이전트를 활용한 실행 파일 분석
- 디컴파일 및 코드 분석
- 정적 분석 및 동적 분석
- 자동화된 리소스 추출
- 그 밖의 역공학 및 분석 기법

**분석 행위 자체의 적법성과 분석으로 얻은 저작물의 이용 가능 여부는 별개의 문제입니다.**
